# DEWEI Brand Assets

德为跨项目共享品牌素材库，供 ERP、MEL、PLC、Word 文档、网页和其他软件使用。

## Logo files

| 文件 | 用途 |
|---|---|
| [`logos/dewei-automation-logo.png`](logos/dewei-automation-logo.png) | Automation 版本，用于自动化、ERP 和软件界面 |
| [`logos/dewei-logo-color.png`](logos/dewei-logo-color.png) | 通用蓝绿色主标，用于 Word、网页、PLC/MEL 文档和非 Automation 场景 |

## 使用规则

- 项目引用固定版本或提交，不要各自复制后私自改色、裁剪或重绘。
- 需要深色背景时，在项目中保持原图比例并使用适配的背景处理。
- 新增 logo 变体时，先补充用途说明和来源，再放入 `logos/`。
- 本仓库只保存品牌源资产和说明，不放具体项目代码、CAD/SW 工程模板或压缩包。
